🔥 Production Scenario

An application is suddenly killed and restarts automatically. You suspect a memory problem. What would you check? 

free -h
ps aux --sort=-%mem | head
dmesg | grep -i oom
journalctl -k | grep -i oom
vmstat 1

Check memory pressure, process consumption, swap usage, kernel logs, memory leaks, and whether the OOM Killer terminated the process.
