⏰ Cron & Scheduled Jobs

Schedule automation, scripts, backups, cleanup jobs, and recurring tasks.

⚡ Quick Revision

Task → Schedule → cron → Execute → Log Output → Verify Result

Cron Format

* * * * * COMMAND
│ │ │ │ │
│ │ │ │ └── Day of week
│ │ │ └──── Month
│ │ └────── Day of month
│ └──────── Hour
└────────── Minute

Core Commands

crontab -l
crontab -e
systemctl status cron
journalctl -u cron

Examples

# Run every day at 2 AM
0 2 * * * /opt/scripts/backup.sh

# Run every 5 minutes
*/5 * * * * /opt/scripts/health-check.sh

Important Concepts

🔥 Production Scenario

A backup script works when executed manually, but the scheduled cron job fails. How would you troubleshoot it? 

crontab -l
systemctl status cron
journalctl -u cron
ls -l /opt/scripts/backup.sh

Check PATH differences, permissions, environment variables, absolute paths, script ownership, and cron logs.
