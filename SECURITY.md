# Security Policy

## Reporting a vulnerability

Please do not publish exploitable security details in a public issue. Use the
repository's **Security → Report a vulnerability** option when private vulnerability
reporting is available, or contact the maintainer privately.

Include the affected page or file, reproduction steps, impact, and a suggested fix
if you have one. Do not include real passwords, tokens, private keys, or personal data.

## Secrets

This project does not need API credentials. Never commit `.env` files, API keys,
payment information, exported study backups, or other secrets.
